ไฟล์ในโฟลเดอร์นี้ (ยกเว้นไฟล์ README และ sources/) สร้างด้วย `npm run import-data` จาก

- **Namtang GTFS** ของสำนักงานนโยบายและแผนการขนส่งและจราจร (สนข.) กระทรวงคมนาคม

- สัญญาอนุญาต **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/) — ต้องให้เครดิต สนข. ทุกที่ที่แสดงข้อมูลนี้
- ดาวน์โหลด: https://namtang-api.otp.go.th/download/namtang-gtfs.zip

## สิ่งที่เราดัดแปลงจากฟีด

- เลือกเฉพาะ 43 สายตาม `sources/namtang.json` และตัดชื่อให้สั้นลง (เช่น "BTS สยาม" → "สยาม") แก้คำผิด 2 ชื่อ
- ข้ามสถานี/ท่าที่ฟีดระบุว่าปิดปรับปรุง
- ความถี่ = ค่าเฉลี่ยวันธรรมดา 07:00–20:00 จาก frequencies.txt / จำนวนเที่ยว
- ค่าโดยสารจาก fare_rules.txt + fare_attributes.txt (คู่ที่ไม่มีในตารางใช้ราคาสูงสุดของสายนั้น)
- ทางเดินต่อรถสร้างจากระยะห่างระหว่างจุด (ไม่สร้างทางเดินข้ามแม่น้ำเจ้าพระยา)
- เวลาเดินทางใช้ของฟีด ยกเว้น 28 สายที่เวลาในฟีดผิดปกติ ซึ่งประมาณจากระยะทางตามเส้นทางจริงแทน:

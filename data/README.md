# ข้อมูลขนส่ง

ไฟล์ในโฟลเดอร์นี้คือข้อมูลที่ระบบใช้หาเส้นทางและคำนวณราคา รูปแบบแต่ละไฟล์ดูที่ [docs/schema.md](../docs/schema.md)

**ตอนนี้เป็นข้อมูลจริง** จากฟีด Namtang GTFS ของ สนข. (CC BY 4.0) รายละเอียดและสิ่งที่ดัดแปลงอยู่ใน [SOURCES.md](SOURCES.md)
มีรถไฟฟ้าทุกสาย สายสีแดง แอร์พอร์ต เรล ลิงก์ รถไฟสายตะวันออก (กรุงเทพ–หัวตะเข้) เรือด่วนและเรือข้ามฟากเจ้าพระยา
เรือคลองแสนแสบ ภาษีเจริญ และผดุงกรุงเกษม (ยังไม่มีรถเมล์)

## อัปเดตข้อมูล (ไม่ต้องพิมพ์เอง)

1. ดาวน์โหลด `namtang-gtfs.zip` จาก https://namtang-api.otp.go.th/opendata
2. ในโฟลเดอร์ `server/`: `npm run import-data -- path/to/namtang-gtfs.zip` (ใส่ `--dry-run` เพื่อดูผลก่อน)
3. `npm run make-mocks` ให้ข้อมูลจำลองของหน้าเว็บตรงกับของจริง
4. ดูรายงานที่พิมพ์ออกมา แล้วสุ่มเช็กราคา 5 คู่กับเว็บทางการก่อนส่ง PR

อยากเพิ่ม/ตัดสาย เปลี่ยนชื่อ สี หรือกลุ่มค่าโดยสาร แก้ที่ [`sources/namtang.json`](sources/namtang.json) อย่าแก้ไฟล์ json ที่สร้างออกมาตรง ๆ
(นำเข้าครั้งหน้าจะถูกเขียนทับ)

## กฎเหล็ก

1. **ทุกกฎราคาต้องมี `source` และ `checked_at`** — `source` คือ URL หน้าเว็บทางการ หรือ "สำรวจเอง วันที่ ..." พร้อมรูปถ่ายป้ายราคาเก็บไว้ในทีม
2. **ห้ามใช้ตัวเลขที่ AI ตอบ** — AI แต่งราคาหรือรหัสสถานีขึ้นมาเองได้ ให้ใช้ AI แค่แปลงตารางจากแหล่งจริงเป็น JSON แล้วสุ่มเช็กกับต้นฉบับอย่างน้อย 5 รายการ
3. **ห้ามลอกข้อมูลจากแอปหรือเว็บของคนอื่น** ที่เงื่อนไขการใช้งานไม่อนุญาต
4. **รัน `npm run validate-data` (ในโฟลเดอร์ `server/`) ก่อนส่ง PR ทุกครั้ง**

## แบ่งกันเก็บ (วันที่ 1)

| ใคร | เก็บอะไร |
|---|---|
| คนหลัก | รถไฟฟ้าที่ผ่านพื้นที่เดโม: สถานี ลำดับ จุดเชื่อมต่อ ตารางราคา สีประจำสาย / รถไฟ 1 สาย (ถ้ามีเวลา) |
| เพื่อน | เรือด่วนเจ้าพระยา (+ เรือคลองแสนแสบถ้าผ่านพื้นที่เดโม) และรถเมล์ 3–5 สาย |

**รถไฟ (`mode: "train"`):** เก็บเฉพาะช่วงที่ใช้เดินทางในกรุงเทพฯ และปริมณฑล เช่น สายตะวันออกช่วงจากแถว KMITL เข้าเมือง ไม่ทำรถไฟทางไกลข้ามจังหวัด (ราคาแยกชั้นและขบวน ต้องมีตารางเวลาจริง)

**พิกัด (`lat`, `lon`):** แผนที่วาดจากค่านี้ ต้องเช็กว่าตรงตำแหน่งจริงบน OpenStreetMap ทุกจุด

เลือกพื้นที่เดโมให้แคบก่อน เช่น เส้นทางจาก KMITL เข้าเมือง ดีกว่าเก็บทั้งกรุงเทพฯ แต่ไม่ครบ
เสร็จแล้วแก้เส้นทางตัวอย่างใน `client/src/presets.js` ให้เป็นเส้นทางจริงในพื้นที่เดโม

**สีประจำสาย:** ใส่ `"color": "#RRGGBB"` ในแต่ละสายตามสีทางการ หน้าเว็บใช้สีนี้วาดเส้นและตั๋วราคา

## แหล่งข้อมูลที่ใช้ได้

- เว็บไซต์ทางการของผู้ให้บริการแต่ละระบบ (รายชื่อสถานีและตารางค่าโดยสาร)
- Namtang API ของ สนข. (ต้องขอสิทธิ์ก่อน): https://namtang-api.otp.go.th/about
- ไฟล์ GTFS สายรถเมล์ของ Longdo Map (เช็กเงื่อนไขการใช้งานก่อนใช้): https://map.longdo.com/download/longdomap
- พิกัดสถานี: OpenStreetMap (ต้องใส่เครดิต "© OpenStreetMap contributors" ในหน้าเว็บ)
- ประกาศนโยบายค่าโดยสารของรัฐ → ใส่ใน `policies` ของ `fares.json`

## ตั้งชื่อ id

`<ระบบ>-<รหัส>` เช่น `BTS-<รหัสสถานี>`, `MRT-<รหัสสถานี>`, `ARL-<รหัสสถานี>`, `CPX-<รหัสท่าเรือ>`, `BUS-<สาย>-<ลำดับป้าย>`
ใช้รหัสทางการของสถานี/ท่าเรือเมื่อมี ป้ายรถเมล์ไม่มีรหัสทางการ ให้ใช้เลขสาย + ลำดับป้าย
